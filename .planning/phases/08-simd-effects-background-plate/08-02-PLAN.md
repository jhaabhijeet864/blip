    1. Calibration state machine: `Uncalibrated`, `Countdown { remaining_secs: f32 }`, `Sampling { frames_collected: usize, accumulator: Vec<u32> }`, `Ready`.
    2. Multi-frame noise-reduction accumulator: Averages 10 consecutive frames into a sharp, noise-free `RgbImage`.
    3. Real-time LAB Luminance compensation (`compensate_luminance(&self, live_frame: &RgbImage, mask: Option<&[u8]>) -> RgbImage`):
       - Measures peripheral background luminance in live frame (ignoring subject mask zone).
       - Compares against stored clean plate baseline luminance.
       - Derives scaling factor `k = clamp(live_luma / baseline_luma, 0.65, 1.45)`.
       - Adjusts clean plate RGB values dynamically to match the current ambient light of the room.
  </action>
