  <action>
    Implement `ThanosDisintegration` in `crates/blip-core/src/effects/thanos.rs`:
    1. Define `Particle` struct using `glam::Vec2` for pos, vel, and color [u8; 3], alpha: f32, size: f32, life: f32, max_life: f32.
    2. Fixed pre-allocated particle pool of 3,500 particles.
    3. `step(dt: f32, mask: &[u8], frame: &RgbImage, width: u32, height: u32)`:
       - Advances progressive vertical erosion front from bottom of silhouette upwards.
       - Emits new ash particles from eroding silhouette pixels, copying exact RGB color from `frame`.
       - Applies parallel physics via `rayon::par_iter_mut()`:
         - Upward buoyant acceleration `Vec2::new(0.0, -90.0)`.
         - Trigonometric pseudo-curl turbulence `Vec2::new(sin(y*0.03)*30.0, cos(x*0.03)*15.0)`.
         - Drag coefficient (0.96) and lifetime decay.
    4. `render(target: &mut RgbImage, background: &RgbImage)`:
       - Blends remaining subject pixels below the erosion front with the background plate.
       - Splats active ash particles onto the target buffer with alpha weighting.
  </action>
</task>
