<objective>
Implement main-world WebRTC `navigator.mediaDevices.getUserMedia` stream interception pipeline that safely wraps the hardware camera, routes frames through an offscreen processing canvas, and returns a 30 FPS synthetic stream to Google Meet, Microsoft Teams, and Zoom Web.

Purpose: Removes the requirement for OBS Studio or virtual camera drivers in browser video calls by hijacking the camera stream directly inside the browser context.
Output: Injected stream interceptor module, WebRTC pipeline, message listener, and automated test suite.
</objective>

  <action>
    1. Create `extension/src/types.ts`:
       - Define `BlipMessage`, `BlipConfig`, `StreamProcessingState`, and event payload interfaces.
    2. Create `extension/src/stream-interceptor.ts`:
       - Store original `navigator.mediaDevices.getUserMedia`.
       - Implement `BlipStreamInterceptor` class:
         - Method `interceptGetUserMedia(constraints)`:
           - Request real user media with original method.
           - If video track present, set up hidden `<video playsinline muted>` and processing `<canvas>`.
           - Hook render loop at 30 FPS to draw video frames into canvas.
           - Generate output stream with `canvas.captureStream(30)`.
           - Append audio tracks from real stream into output stream.
           - Return synthetic output stream to calling page.
         - Method `processFrame()` hook ready to connect vision models and particle renderers.
         - Method `toggleMute(enabled)` to manage audio track state.
         - Event listeners for `window.postMessage` handling configuration changes and manual triggers.
    3. Create `extension/src/injected.ts`:
       - Entry point bundled into `dist/injected.js`.
       - Instantiates `BlipStreamInterceptor` and monkey-patches `navigator.mediaDevices.getUserMedia` immediately upon evaluation.
  </action>
</task>
